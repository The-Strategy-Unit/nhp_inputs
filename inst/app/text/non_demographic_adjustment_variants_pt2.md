To use Variant 3 for comparative purposes you must create a new scenario:

1. Select the 'create new from existing' radio button on the landing page of the OpenPlan Hospital Demand Model's inputs app.
2. Choose the name of the previous scenario you wish to re-run with Variant 3.
3. Provide a new, unique name (consider appending the original scenario name with e.g. '-ndg3').
4. This time, select 'Variant 3' from the dropdown on this page. For a true comparison, all other parameters should remain the same.

Currently, the non-demographic adjustment for inpatients maternity activity is set at 1 (in both Variants) which represents no change.
This assumption is currently under review and may be revised in later versions of the model.

For more information about the use of Variant 2 and Variant 3, see the [OpenPlan demand model documentation](https://connect.strategyunitwm.nhs.uk/nhp/project_information/modelling_methodology/non-demographic_growth.html).
